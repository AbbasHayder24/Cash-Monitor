# FinFlow v2 — تطبيق إدارة المال القابل للتخصيص الكامل

تطبيق ويب متكامل لتنظيم الشؤون المالية الشخصية بتصميم **Liquid Glass Classical**، مبني بملفات نظيفة ومنفصلة ويعمل مباشرة في أي متصفح أو داخل **Spck Editor** دون أي أدوات بناء.

## أبرز إمكانيات التعديل والتخصيص (الجديد في الإصدار v2)

### 1) التعديل المباشر من داخل واجهة التطبيق
- **تعديل المعاملات ونسخها**: يمكنك الآن تعديل أي معاملة (الوصف، المبلغ، النوع، الفئة، التاريخ، والملاحظات) أو نسخها بنقرة واحدة من لوحة التحكم أو جدول المعاملات.
- **تعديل أهداف الادخار والسحب منها**: عدّل اسم الهدف، المبلغ المستهدف، أو الرصيد المدخر مباشرة، مع دعم الإيداع (`+`) والسحب (`-`).
- **إدارة الفئات بالكامل**: أضف فئات جديدة للمصروفات أو الدخل، أو عدّل الاسم (عربي/إنجليزي)، الأيقونة، اللون، وتصنيف الفئة (احتياجات أم رغبات).
- **تخصيص قاعدة التقسيم (50/30/20)**: عدّل نسب الاحتياجات والرغبات والادخار بحرية (أو اختر من القوالب الجاهزة مثل `60/20/20` أو `70/20/10`).
- **إضافة عملات مخصصة**: أضف أي عملة جديدة مع رمزها وسعر صرفها مقابل الدولار، إلى جانب تعديل أسعار الصرف الحالية.
- **استوديو الهوية والمظهر والتخطيط**: غيّر اسم التطبيق، الشعار، العنوان الفرعي، لون التمييز الرئيسي، فعّل **الوضع المضغوط للهاتف**، وتحكم بظهور وإخفاء أقسام لوحة التحكم ونسبة تحذير الميزانية.
- **تصفية حسب الشهر + أدوات بيانات متقدمة**: صفِّ الأرقام حسب الشهر أو كل الفترات، صدّر جدولك إلى **CSV** (يدعم العربية في Excel) أو **JSON**، أو امسح البيانات التجريبية للبدء بسجل فارغ مع الاحتفاظ بإعداداتك.

### 2) التعديل البرمجي السريع عبر ملف واحد (`js/config.js`)
إذا أردت تغيير الإعدادات الافتراضية من الكود مباشرة، افتح ملف **`js/config.js`** وستجد جميع القيم منظمة ومشروحة بالعربية داخل كائن **`APP_CONFIG`**:
- `brand`: اسم التطبيق والشعار والعنوان الفرعي.
- `defaults`: اللغة، المظهر، العملة، اللون، الوضع المضغوط، نسبة التحذير، ونسب قاعدة التقسيم.
- `defaultCategories`: قائمة الفئات الافتراضية بألوانها وأيقوناتها.
- `defaultRates` و `defaultCurrencies`: أسعار الصرف والعملات الافتراضية.

## هيكل الملفات
- `index.html` — الهيكل الرئيسي والنوافذ المنبثقة.
- `css/theme.css` — متغيرات الألوان والمظهر الليلي والنهاري.
- `css/components.css` — تنسيق البطاقات والجداول والوضع المضغوط.
- `js/config.js` — **ملف الإعدادات المركزي (`APP_CONFIG`)**.
- `js/i18n.js` — القاموس الثنائي (العربية والإنجليزية).
- `js/currency.js` — محرك العملات الديناميكي.
- `js/storage.js` — الحفظ التلقائي المحلي وترحيل بيانات الإصدار السابق.
- `js/charts.js` — المخطط الدائري التفاعلي بألوان الفئات المخصصة.
- `js/app.js` — المتحكم الرئيسي في التفاعل والتعديلات.
